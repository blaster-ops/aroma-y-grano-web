02 / UN POCO SOBRE MÍ

Aprender haciendo.
Crear con intención.

Soy José Miguel Tapia Adán y este es mi portafolio académico de desarrollo web. Aquí reúno proyectos que conectan una necesidad concreta con una experiencia que se puede explorar desde el navegador.

Mi proceso de aprendizaje combina estructura con HTML, presentación con CSS e interacción con JavaScript. Cada proyecto es una oportunidad para practicar diseño adaptable, navegación clara y publicación en la web.
